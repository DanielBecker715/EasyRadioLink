EasyRadioLink 1.0.0 is the first release of EasyRadioLink: a standalone digital radio for voice communication.
Connect to a server, tune your radios to a frequency and talk to everybody on the same frequency - with the sound of
real radios. No game or other software is needed.

## Downloads

| File | Who needs it |
|---|---|
| `EasyRadioLink-Client-1.0.0.zip` | Everybody who wants to talk. Extract it and start `EasyRadioLink.exe`. |
| `EasyRadioLink-Server-1.0.0-Windows.zip` | Only whoever hosts a server on Windows: `Server\EasyRadioLink.Server.exe` (server with window) and `CommandLine\EasyRadioLink.Server.Cli.exe` (command-line server). |
| `EasyRadioLink-Server-1.0.0-Linux.tar.gz` | Only whoever hosts a server on Linux (x64): `EasyRadioLink.Server.Cli`. |

No installation is needed: extract the archive and run the program. Every download contains `README.txt` (user
guide), `LICENSE.txt` and `THIRD-PARTY-NOTICES.txt`.

## Features

- **Radios**: up to 10 radios per user with frequency, modulation (AM, FM, digital), volume, guard receiver, preset
  channels and "transmit on several radios at once". Default set: CB, PMR446, VHF airband, UHF tactical, HF long range
  and a digital radio. Radios remember their settings between sessions; own layouts via `radios-custom.json`, and a
  server can provide a common layout.
- **Radio Panel**: compact always-on-top window with frequency step buttons and direct entry, channels, guard,
  encryption, volume, TX/RX indicators with the transmitter's name and the number of users on the frequency.
- **Sound models**: every radio has a sound (CB, walkie-talkie, airband, tactical, HF, vintage, digital, ...) that
  shapes how the others hear you. Own models can be added as JSON effect chains.
- **Radio realism**: frequency-dependent static, squelch tail at the end of a transmission, TX/RX clicks, FM tone,
  optional half-duplex radios and interference of simultaneous transmissions.
- **Background sound**: optional jet, prop or helicopter noise behind your voice.
- **Encryption**: radios with the same key (1-252) understand each other; everybody else hears scrambled noise.
- **Radio check**: on a server with default settings, transmissions on 27.405 MHz (CB channel 40) and 446.19375 MHz
  (PMR channel 16) are echoed back so you can hear how you sound.
- **Server**: server with window for Windows and a command-line server for Windows and Linux; optional server
  password, clean frequencies without radio effects, server preset channels, mute/kick/ban, UPnP port forwarding,
  transmission log and an optional HTTP admin API.
- **Controls**: push-to-talk and radio selection on keyboard, mouse, joysticks and gamepads; optional MP3 recording.

## Requirements

- **Client**: Windows 10 or 11 (64-bit), the [.NET 10 Desktop Runtime (x64)](https://dotnet.microsoft.com/download/dotnet/10.0)
  and the Microsoft Visual C++ Redistributable (x64), which the audio libraries need. Most PCs already have the
  Visual C++ Redistributable; if EasyRadioLink has no sound or reports a missing DLL, install it from
  <https://aka.ms/vs/17/release/vc_redist.x64.exe>.
- **Server with window**: Windows 10 or 11 (64-bit) and the .NET 10 Desktop Runtime (x64).
- **Command-line server**: self-contained, no .NET installation needed. Windows 10/11 x64, or Linux x64 with glibc
  (for example Debian, Ubuntu, Fedora).

The executables are not code-signed, so Windows SmartScreen may show a warning on the first start
("More info" > "Run anyway").

## Quick start

1. **Server**: extract the server download into a folder where you may write files and start
   `Server\EasyRadioLink.Server.exe` - or on Linux: `tar xzf EasyRadioLink-Server-1.0.0-Linux.tar.gz`,
   `cd EasyRadioLink-Server-1.0.0`, `./EasyRadioLink.Server.Cli --password=secret`. Open TCP and UDP port 5010 in the
   firewall and forward it in your router.
2. **Client**: extract the client download and start `EasyRadioLink.exe`. Choose microphone and speakers on the
   Radio tab and assign Push-To-Talk on the Controls tab.
3. Enter your name, the server address (`host:5010`) and the password, if any, then click **Connect**.
4. The Radio Panel opens. Tune to the same frequency and modulation as the others, hold PTT and talk.

## Notes

- The server password keeps strangers out, but it is sent unencrypted. Do not reuse a valuable password.
